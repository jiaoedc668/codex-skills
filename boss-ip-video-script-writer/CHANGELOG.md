# 版本记录

版本唯一值为SKILL.md的metadata.version；已发布标签不移动。发布流程见references/release-management.md。

## 1.1.0 — 2026-09-10

兼容新增普通 ChatGPT Chat 读取方式，不改变 schema v6、人物 schema 3、本地反馈状态机、Word 授权门或 Codex 本地执行流程。

### 本次优化

- 新增 `CHATGPT.md`，只处理普通 ChatGPT Chat 的环境差异；本地 Codex 默认忽略，不复制第二套创作规则。
- 新增 `chat-context/` 公开安全快照骨架，分别承载人物、近期反馈、近期选题和共享抽象偏好的脱敏投影。
- 快照默认 `not_synced`，未同步时网页 Chat 回退到 `persona-template.json` 和当前会话，不伪造本地台账、脚本执行、哈希或验收结果。
- `web-access` 在普通 Chat 环境下允许由 ChatGPT 原生 Web Search 替代，但 10 万赞原作、内容可读性和其他研究硬门不降低。
- README、AGENTS 与版本维护规则增加公开快照边界：原始业务内容、完整台账、正式交付和运行产物仍不进入 Public 仓库。

### 验证

本次未修改 Python、schema 或生成器逻辑。公开快照 JSON 骨架已做语法检查；ChatGPT 适配文档按新写、标题、局部修改、联网研究、本地脚本不可执行和正式 Word 六类路径进行静态审读。

当前 ChatGPT GitHub 集成只有读取权限，无法直接在远端提交；因此本条仅作为待本地 Codex 应用后的 1.1.0 发布记录。正式发布前仍需本地运行仓库既定 unittest、compileall、git diff --check，并由本地 Git 创建/推送 `boss-ip-v1.1.0` 标签。

## 1.0.0 — 2026-09-09

首次独立语义版本基线。候选schema v6、人物schema 3继续保留，历史v5/v4兼容读取；人物profile_revision更新为2，旧候选须使用迁移前人物快照复验。

### 本次优化

- 增加新写、参考续写、局部修改、标题和发布介绍入口；抖音、视频号按用户指定处理，纯包装不重跑新选题研究。
- 标题与首两句联审兑现，观点解释遗漏因素，对白回应现实阻力，结尾集中一个主要落点；高赞研究写清适配条件与实际采用位置。
- 人物模板统一为persona-template.json，初始化器从单一模板加载；迁移器保存旧字节快照、追加观点版本、更新现役行为及时长，删除重复legacy块及失效行为。普通init不覆盖已有实例。
- 修复用户指定数量时批次CLI、完整性校验和反馈投影仍写死三条的问题；非三条逐项统计并与三条批次标准隔离。
- 新增版本与清理规则、范围化Git提交约定，修正Word编号登记路径及项目交付入口链接。
- 仓库当前树移出历史业务人物实例与两份台账，归回业务项目留档；旧测试改用无业务身份信息的稳定夹具。共享偏好自身测试独立运行，跨Skill联调仅在另一个Skill已安装时运行。

### 纳入首个版本的已有改动

本版同时纳入版本编号前已在本地使用的10万赞原作研究门、标题字段与公开展示、口播主题对齐、批内语义差异审读、共享抽象创作偏好及其测试。它们不是本次新创功能；此前未提交状态已在业务项目留存基线。

### 验证

新增人物迁移4项及指定数量3项定向测试通过；完整本地环境212项unittest全部通过，compileall与git diff --check退出0。独立目录运行212项，其中210项通过、2项因未安装商品Skill而跳过的跨Skill联调；Boss自身的共享偏好校验与CLI测试继续执行。

Skill版本字段、相对链接及安装Junction哈希核验通过。业务项目保存三条历史候选按旧快照复验、过期引用拒绝、1/2条批次完整性及旧稿/台账/交付保护哈希证据。官方quick_validate在本机因缺少PyYAML无法启动，未新增依赖；独立结构核验不冒称官方检查通过。

机器检查只证明完整性与兼容边界，不代表用户可拍评价或传播效果。仓库当前树已移除业务文件，已有Git历史未重写。
