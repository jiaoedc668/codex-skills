# schema v6 剧情对白与单人口播

本文件只负责对白动作、自然口语、基调、幽默和候选阶段的低成本拍摄表达。事件因果见 `story-engine.md`，人物事实边界见 `authorized-fiction-persona.md`。

## 对白动作

历史v5对白动作如下，仅用于读取旧稿。v6使用tell/ask/judge/advise/object/decide/explain，不强制每句争夺筹码：

- `request`：提出眼前请求或要求对方拿出事实；
- `conceal`：为了面子或利益暂时隐瞒关键信息；
- `refuse`：拒绝当前方案并守住边界；
- `push_back`：用现实理由顶回去；
- `save_face`：给自己或对方留台阶，但不取消冲突；
- `decide`：作出会改变下一步的决定。

必要背景应自然交代具体处境。剧情每句回应对方；口播每句推进理由。不能机械删背景，也不能让角色主动递出作者答案。

## 自然口语

剧情以“70% 大白话，30% 传播句”为创作启发：大多数话先像真实聊天，通常只需一个主要传播句，最多再有一个次级记忆点。不是字符比例，不计数、不打分，也不要求必须有金句。短例见 [现役创作校准](creative-quality-calibration.md)。

- 一句只做一件事，长说明拆成真正的来回交锋。
- 剧情允许停顿、改口、嘴硬和承认位置。口播允许讲有大格局的人生道理，但每一层判断都要有具体理由、对照或现实例子支撑，真诚而不训话。
- 角色名只写在 `speaker`，台词里不重复报身份。
- 具体说谁、多少钱、哪张单、什么时候做、做完会怎样；少用抽象名词串。
- 不连续写同构排比，不堆口头禅，不为了结尾金句牺牲前面的人话。
- 重点警惕“真正的问题是、本质上、你需要明白、真正重要的是、这背后的核心逻辑、底层逻辑、认知跃迁、价值闭环、先说结论”等模型腔。除非场景和人物确实会这样说，否则不用；不能拿角色身份作空泛说教的借口。
- “要理解、要负责、加强沟通、做好处理”不能单独构成判断，必须落到可见选择或后果。
- 道具揭晓前不能把它说死成另一件东西；揭晓后必须改变行动。

完成后按正常说话方式通读，只改听起来拗口、角色不会这样说或一口气说不完的句子，不把稿型标签变成机械长度指标。

演员读得出口测试：每句问“一个普通人在真实聊天状态下，会不会这么完整地说出来？”不会就拆成自然的来回，保留语气、停顿和未说完的意思。再问人在这个情绪里会不会这么说；逻辑正确但不像人话仍要改。

删掉人物名再听：若像公众号段落、情感主播或咨询师总结，回到当前事实重写。“父母能给孩子的是……不是……”“真正的朋友是……还是……”“最可怕的不是……而是……”等并非全禁，但反复使用会暴露作者。保留本故事最强的一句，其余改成普通话；不连续排比、不要求押韵或升华，也不把长分析切成短句假装大白话。

**不准替观众总结太早。** 冲突刚出现时先让人物做事、说话，不立刻把它命名为“婚姻价值”“中年困境”“家庭责任”。观点晚半拍出现；能让观众先自己得到结论的地方，不抢着解释。主要为了作者解释主题的台词，优先删除或改成角色行为。

“直接”不等于删光背景或固定六句收口。人物为什么急、为什么不肯退让，观众必须听得懂；对白长短服从这一需要。已获认可的铺垫不能为追求短句被一并重写。

## 有分量的收尾

每篇确定一个主要落点。建议、人物回应和金句可以连着出现，但必须各有作用；若三段都在重复“要理解、要支持、要负责”，收成一次结束。不在自然结束后另附同义的“结尾金句”。

剧情的金句要回答眼前冲突，不突然另讲一段人生道理。口播的主题本来就可以是人生大判断，收尾应把前文的理由和例证压缩成一句能说出口、能被记住的话。两种形式都保留人的难处，不靠羞辱对方制造力度。

结尾必须来自当前故事本身。删去人物名字和具体身份后，最后一句若能原封不动套到另外5篇家庭、职场或养老稿里，就过于空泛。优先回收已经出现的动作、冲突、损失或被忽略的代价。避免突然上升到人生、格局、责任、幸福、珍惜、人品，除非前文确实支撑；口播同样要由本篇理由托住，不能靠题材标签豁免。

例如借钱加盟的冲突落在翻身与家庭积蓄，收尾“越是急着翻身，越不能把一家人的退路押上”有前文支持。换题不能照抄这个句式，也不为“金句”硬造万能大道理。

金句与行动可以共存。动作证明人物真的作了选择，末句说清这个选择的分量；不能因反感说教而全面禁用总结，也不能因为一句金句获认可，就要求每篇押韵、排比或同一种收口。

再做一次“不过度收口”检查：正文已说透的判断，结尾不换文艺说法重复。优先回收前面的一句原话、数字、行为、损失或选择；回收必须推进或暴露仍在的矛盾，不能只是漂亮复述。不为证明发哥正确把双方解释得滴水不漏，也不机械加一句“你怎么看”。朋友可保留顾虑，最后一句也可以由朋友说。

## 先难处，后出口

让观众听懂双方不肯退的具体原因，再落到足以改变眼前判断的现实出口；背景按理解需要保留，不展开双方完整心理分析。温暖不等于发哥替所有人买单，也不等于反方认错退场。可以只问清一个必要条件或指出待做的选择，不要求当事人当场答应；方法展开尺度见 story-engine.md。

争议围绕做法、责任、边界与选择。不羞辱员工、女性、老人、年轻人或家庭角色，不消费疾病、灾难和未成年人隐私，不用开除、扣薪、违法用工或老板霸凌制造爽感。

## 幽默顺序

非严肃题材默认一处自然笑意，按以下顺序选择：

1. 维护尊严的温暖机锋；
2. 责任绕一圈又落回当事人的轻幽默；
3. 账单、排班、时间和生活习惯形成的具体反差；
4. 有分寸的正面顶嘴。

严肃题材可以没有幽默。笑点必须推进选择或缓和尊严，不能靠方言模仿、网梗、羞辱或让对方显得愚蠢。没有自然位置就不硬塞。

## 低成本拍摄表达

剧情默认一个主要场景，发哥露脸加一名讲自己难题的朋友或同事；口播只有发哥。道具只在帮助理解事件时使用。常用地点是办公室或公司公共区域；题材需要时可换家中公共空间、朋友聚会或其他可获得的日常地点。员工、朋友或亲戚可以露脸或用画外音，但都要有自己的目标与筹码。

动作写镜头能看到的结果，例如“把两张单据分开放好”；不写“若有所思”“感到温暖”。镜头以固定中景、关键物特写和必要反应近景为主。候选只列真正必要的动作与镜头，场景、演员、道具、完整分镜和字幕在普通文案确认后或明确专项制作授权下补齐。

## 标题与开头一起审读

剧情标题先做压缩：优先一口气读完，只抓一个主要冲突，常用人物关系加反常行为或结果。通常约8～14个中文字只是参考，必要身份或数字可以更长，不作 Integrity FAIL。逐项删去不影响冲突理解的背景、时间、解释和数字；数字只有本身构成最大冲突点时才保留。正文补背景，标题让人想点开，不为凑短损害自然表达。压缩示例见 [现役创作校准](creative-quality-calibration.md)。

先用一句话说清观众与这件事的利害，再比较适合本稿的冲突、利益后果、身份反差或认知悬念；内部比较不变成固定标题配额。标题不能只复述题材或概括道理，也不能用正文没有的失业、离婚、暴富等结果加码。

连续读标题和首两句：观众点进来想知道的问题，开头是否立即承接？再读结尾：正文是否完成标题承诺？只改标题时保留正文，选择现有正文能承载的力度。不要以“视频号要稳”为由自动削弱用户要求的吸引力；平台差异由实际反馈校准。

前3秒测试：标题＋前两句至少满足两项——明确人物、具体行为、具体损失、明显不公平、明显反常识、一句让人想反驳的话。随后必须明确回答“观众读完标题和前两句以后，现在最想知道什么？”答不出就 Hook 失败。不是勾满两项就自动好看；疑问要由正文兑现，不靠隐瞒必要背景造悬念。

“我朋友最近遇到一个事情……”“婚姻里其实有很多问题……”“人到中年才发现……”“真正重要的是……”默认重写，除非后面立即有极强的具体事件承接。此测试由作者语义审读，不新增 hook_score 或其他评分。

通常1～2个来回内交代“人物＋异常行为/损失/冲突”，减少“最近挺烦”“事情是这样的”等入场铺垫。结果或情绪先行也要尽快接上具体事；不要为悬念藏住必要背景，不要求所有稿用同一种直给开头。

## 时长估算与限制
剧情约60秒、尽量90秒内；口播约30秒、尽量45秒内。估算记录净台词字符量、每分钟语速和停顿秒数，公式为台词量/每分钟语速*60+停顿。数字按实际读法换算，或说明简化计数字符的局限。建议以每分钟240—280个中文字给出区间，不为达标临时提高假定语速。未使用TTS或实际朗读，不声称实测。超参考先删重复；仍不能收束则记录原因，保留人物边界和故事完整优先。

动作、镜头、前史都不得让发哥替人落实安排，建议由当事人决定执行。标题强度应有正文中的行为与后果支持，不能泛化攻击性别群体。
