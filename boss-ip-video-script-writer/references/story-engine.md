# 双形式故事与观点构造

## 人物边界
发哥是建议者，可以直接反驳有错的当事人，不能成为事件参与者、介绍人、安排者或代办人。对白、动作、镜头、前史同样遵守；他不能借款、招聘、催债、联系中介、调班或落实家务来兑现观点。不必承担别人生活中的代价，不要求当场解决问题。

## 剧情 默认story
先用 Raw Draft 写出自然发生的故事，通过 Creative Review 后再用蓝图描述当事人怎样理解问题、漏算了什么处境或代价、哪条事实改变判断。把已成立的内容写进现有字段，不另加schema字段或分数。schema 描述故事，不生成故事；不为反转强行否定常识，也不擅改用户核心立场。

剧情冲突首先表现为人物做了什么，而不是作者告诉观众这个人持有什么观点。“我老公不尊重家庭主妇”还不是事件；“他天天嫌我不上班没贡献，我真找到8000块工作后，他又不让我去”才有人正在做事。“哥哥姐姐不愿承担养老责任”是概括；“他们一人愿意出5000，但都让我这个工资最低的辞职照顾老人”才给出了损失与选择。示例金额属于虚构情节，不是现实统计或发哥个人事实。

保留 strongest_counterargument 的现实动机，但把它写成人会说的话。每篇剧情尽量找到一句 emotion trigger line / 情绪触发句，不新增字段。“丈夫认为妻子的收入不足以覆盖家庭照护成本”可变成角色会说的“别人家女人不也这么过吗？”让观众自然觉得“凭什么”“我家就是这样”，同时用具体处境托住他不肯退的理由。不得把反方写蠢、写成纯恶人，或靠性别、年龄、职业羞辱制造冲突；例句是机制示范，不是每篇必套台词。

先写具体处境、委屈、选择及后果。朋友或同事带自己的难题来讲；前两句让观众知道谁、什么事、眼前代价。对方可以争辩、补充信息和保留难处，不能只负责递标准答案。

发哥依据听到的事实追问、分析、批评或建议。新信息应影响理解或下一步，而非机械设置翻转。结尾落到当事人可以做的选择或沟通边界，可以尚未解决；不能以“回去沟通一下”笼统收口。原因、障碍和下一步互相对应，拍摄不依赖新增很多演员。

除非事件极其明显，发哥不默认从第一句就完整理解问题。允许初步误判、被新信息打断、停顿、嘴硬一下、被对方原话架住、改口和修正建议；可信度来自听完事实以后会判断。判断可以不完整，不能为反转故意显得愚蠢，也不要求每篇必有误判。

剧情中发哥原则上最多保留一次较完整的观点输出。其余位置优先短问句、反问、打断、重复对方矛盾、具体追问、一句话判断或停顿后改口。连续出现多段完整大道理时优先重写，不把一段说理拆成几行伪装交锋。

逐轮检查剧情对白是否补充处境、提出真实阻力或改变判断与选择；同一句判断换说法重复多轮就合并。反方最强顾虑要得到回应，例如没钱时不能仅以“花钱解决”结束。允许谈完仍不完全认同，不让对方突然认错替发哥完成论证。

## 口播monologue

仅发哥。先定一个能覆盖多数人经验的人生原则、人品价值或处世智慧；家庭、人情、钱或关系中的小事只作证明该原则的例子，不能反客为主。

第一句用强判断、反常识或悬念建立停留理由。中段用2至4个不重复的理由、对照或例证推进，认真回应一个现实反驳。结尾是由前文自然得出的人生判断，要有记忆点和人情味，不能只押韵喊口号。不强塞第二说话人、现场双方目标或结果动作，不依靠发哥虚构履历背书。

口播判断力度来自解释被忽略的一层。先检查观众听完多理解了什么，再检查理由数量；不能用多个同义理由凑满2至4项。

## 推倒重搭的依据

事件说不清、委屈没有行为支持、反方被写蠢、出口答非所问、发哥实际介入、结尾突然增加新观点，都应重搭。重复解释或改长字数不能修复。用户明确只改某段时，先守住指定范围；无法局部修复才说明具体矛盾，不能擅自扩写其他稿。

旧v5蓝图里的immediate_wants、fage_cost和result_action_id仅用于历史兼容，不要求新剧情或口播照填。
