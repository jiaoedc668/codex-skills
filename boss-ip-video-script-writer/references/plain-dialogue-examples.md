# 对白校准样例

这些片段只示范“对白怎样把动作拍出来”，不能复制为候选。

## 样例一：规则回到老板身上

弱：
- 员工：工具能不能替我做事？
- 发哥：工具只是工具，关键还是人。

强：
- 员工：你说谁先做完谁先走，我用AI十分钟做完了。
- 发哥：客户回了三个问号，你先别走，我陪你把这三个问号弄明白。
- 员工：那你也没走成。
- 发哥：规则我定的，坑我也得一起填。

强版中，员工拿规则争取下班，客户反馈改变局面，发哥用“陪着返工”的动作承担自己定规则的后果。

## 样例二：发哥认错

弱：
- 员工：这个安排不合理。
- 发哥：管理要有人情味，我以后会注意。

强：
- 员工：你把周六写成“自愿到场”，后面又加了全员。
- 发哥：……这两个词放一起，是我占便宜。
- 员工：那表还发吗？
- 发哥：（划掉周六）不发。急活我来拆，周一再排。

强版让证据出现、弱点暴露、安排改变；最后一句只解释当场决定。

## 样例三：家庭困境不冒充亲历

弱：
- 发哥：我儿子以前也不听话，后来我告诉他父母都是为他好。

强：
- 画外音：我爸又把体检单藏起来，说不想麻烦我。
- 发哥：你先别和他讲孝顺。今天下班把号挂上，明天陪他去。
- 画外音：工作怎么办？
- 发哥：上午我替你顶一次。回来把单子看懂，比隔着电话猜强。

强版只处理画外音的眼前困境，不把它写成发哥真实家庭史。
